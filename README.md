# Улучшатель промптов по правилам Anthropic

Пишешь запрос к нейросети как попало, получаешь готовый промпт. Внутри правила из официального гайда Anthropic по промптам и из системного промпта Claude Fable 5.1.

Подходит для текстов, кода, разбора документов, картинок и видео. Работает в ChatGPT, Claude, Gemini и Claude Code. Бесплатно, лицензия MIT.

## Что он делает

Запрос: `бот на aiogram падает когда шлют фото без подписи, ошибка NoneType has no attribute lower`

Ответ:

```
<контекст>
Телеграм-бот на Python, библиотека aiogram [впиши: версия]. Падает, когда пользователь отправляет фото без подписи.
Ошибка: AttributeError: 'NoneType' object has no attribute 'lower'
Код обработчика: [впиши: вставь код]
</контекст>
<задача>
Найди причину и исправь обработчик, чтобы бот работал и с подписью, и без неё.
</задача>
<формат>
Сначала одной фразой причина. Потом исправленный код обработчика целиком. Меняй только этот обработчик: остальной бот работает. В конце напиши, как проверить: что отправить боту и что он должен ответить.
</формат>
```

Где фактов не хватает, агент ставит пометку `[впиши: …]` и ничего не выдумывает. Личные данные из памяти и профиля в промпт не переносит.

## Как установить

### ChatGPT, Gemini, Claude в браузере

1. Открой файл [`агент.txt`](агент.txt) и скопируй текст целиком.
2. Создай отдельный проект в ChatGPT или Claude либо отдельный Gem в Gemini и вставь текст в его инструкции.
3. Пиши в этом проекте запросы как обычно.

Держи агента в отдельном проекте, а не в общих инструкциях аккаунта. Иначе он будет переписывать в промпт вообще все твои сообщения, в том числе обычные вопросы.

### Приложение Claude (скилл)

1. Скачай архив [prompt-uluchshatel.zip](https://github.com/lelya040684-cpu/prompt-uluchshatel/releases/latest/download/prompt-uluchshatel.zip).
2. Открой [Customize → Skills](https://claude.ai/customize/skills), нажми «+» → Create skill → Upload a skill и выбери архив.
3. Пиши в любом чате: «улучши промпт: …».

Для скиллов в настройках должно быть включено выполнение кода (Code execution). Скилл включается только по прямой просьбе улучшить или переписать промпт, обычные разговоры он не трогает.

### Claude Code

Скилл:

```bash
git clone https://github.com/lelya040684-cpu/prompt-uluchshatel.git
mkdir -p ~/.claude/skills && cp -r prompt-uluchshatel/prompt-uluchshatel ~/.claude/skills/
```

Агент (по желанию, работает в отдельном окне и возвращает только готовый промпт):

```bash
mkdir -p ~/.claude/agents && cp prompt-uluchshatel/agents/prompt-uluchshatel.md ~/.claude/agents/
```

После установки перезапусти Claude Code. Вызов: «улучши промпт: …» или команда `/prompt-uluchshatel`.

## Как удалить

**ChatGPT и Claude в браузере:** удали проект с агентом или сотри текст агента из инструкций проекта.

**Gemini:** открой список своих Gem и удали Gem с агентом.

**Приложение Claude:** открой [Customize → Skills](https://claude.ai/customize/skills), нажми на скилл prompt-uluchshatel. Чтобы выключить, передвинь переключатель справа вверху. Чтобы удалить совсем, нажми «…» рядом с переключателем → Delete и подтверди.

**Claude Code:**

```bash
rm -rf ~/.claude/skills/prompt-uluchshatel
rm -f ~/.claude/agents/prompt-uluchshatel.md
```

Потом перезапусти Claude Code. Больше скилл нигде следов не оставляет.

## Безопасно ли это

В репозитории только текстовые файлы: инструкция для нейросети, описание и лицензия. Нет программ и скриптов, ничего не запускается само, никуда не отправляет данные, не просит пароли и ключи. Любой файл можно открыть прямо на GitHub и прочитать целиком.

Агенту в Claude Code разрешено только чтение файлов: менять файлы и запускать команды он не может.
